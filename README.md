I work on cross-platform mobile infrastructure: Cordova and Ionic plugins, native SDK integrations, and Angular/TypeScript tooling. Much of my open-source work is about keeping mature production stacks compatible with today's iOS, Android, and third-party SDK requirements.

### Open-source work

| Project | What it does |
| --- | --- |
| [cordova-plugin-fbsdk](https://github.com/MaximBelov/cordova-plugin-fbsdk) | Maintained Facebook SDK integration for Cordova and Ionic, with current Android and iOS support. |
| [cordova-plugin-cross-app-auth](https://github.com/MaximBelov/cordova-plugin-cross-app-auth) | Secure single sign-on between Cordova apps from the same publisher. |
| [cordova-plugin-store-update-check](https://github.com/MaximBelov/cordova-plugin-store-update-check) | Checks Google Play and the App Store for available updates without downloading them. |
| [BarcodeParser](https://github.com/MaximBelov/BarcodeParser) | Actively maintained GS1 barcode parser for JavaScript, published on npm with comprehensive test coverage. |
| [ngx-intercom-messenger](https://github.com/MaximBelov/ngx-intercom-messenger) | Angular 18+ wrapper for the Intercom Messenger JavaScript SDK. |
| [cordova-plugin-bluetooth-classic-serial-port](https://github.com/MaximBelov/cordova-plugin-bluetooth-classic-serial-port) | Bluetooth Classic serial communication for Cordova applications on Android and iOS. |

### What I care about

- Reliable native bridges for cross-platform applications
- Clear upgrade paths for long-lived mobile codebases
- Reproducible testing, CI, and release automation
- Small, focused APIs with practical documentation

### Let's collaborate

If you use one of my projects, bug reports and focused pull requests are welcome. The best place to start is the issue tracker in the relevant repository.
